# Processed data

Run `make data` to regenerate all files in this directory from the unchanged Numbers files in `data/raw/`.

- `responses_long.csv`: one scored response per participant, time point, and item.
- `participant_scores.csv`: target and secondary totals by participant and time point.
- `item_summary.csv`: item-level accuracy by condition and time point.
- `item_key.csv`: canonical target and condition-specific item map.

Participant IDs are experiment codes only. No direct identifiers are stored here.
